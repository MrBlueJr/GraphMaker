# GraphMaker

An interactive math graph creator that lets you draw, visualize, and download mathematical graphs.

## Features

- **Function Plotting** — Type math expressions like `sin(x)`, `x^2`, `2*x+1`
- **Freehand Drawing** — Sketch directly on the graph
- **Pan & Zoom** — Scroll to zoom, drag to pan
- **Customization** — Line colors, widths, and styles
- **Quick Presets** — One-click buttons for common functions
- **Download** — Export your graph as a high-res PNG
